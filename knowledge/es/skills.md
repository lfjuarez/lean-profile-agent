## Splunk

Indexer y Search Head Clustering (single-site y multi-site), Splunk Cloud, SmartStore, SPL avanzado, Enterprise Security (correlation searches, risk-based alerting, data models), Splunk SOAR (playbooks), UBA y UEBA, apps y add-ons propios, Common Information Model (CIM), extracciones de campos con regex, capacity planning y upgrades.

## Onboarding de datos

Universal Forwarder, HTTP Event Collector (HEC), syslog, DB Connect, APIs REST; normalización y enriquecimiento; monitoreo de salud de fuentes (TrackMe).

## Elastic

Elasticsearch, Fleet y Elastic Agent, gestión del ciclo de vida de índices (hot, warm, cold, frozen), Elastic Common Schema (ECS), Watcher, Elastic Security.

## Detección y respuesta

MITRE ATT&CK y MITRE ATLAS, threat hunting, triage e investigación de alertas, reducción de falsos positivos, evaluación de cobertura de detección, ingeniería de detección, diseño de playbooks de SOAR.

## Infraestructura y cloud

Linux, Windows Server, AWS (EC2, S3), Azure, Google Cloud (Cloud Run), Terraform, redes (TCP/UDP, HTTP, SSH, TLS).

## Automatización e IA

Python (pipelines, APIs, automatización), Shell, PowerShell, TypeScript y Node.js, SQL y PL/SQL. Agentes LLM (Claude, OpenAI, modelos locales), RAG (embeddings, bases vectoriales, chunking), evaluación de salidas, prompt engineering, guardrails contra inyección de prompts, servidores MCP a medida. Web: Next.js, Prisma, PostgreSQL, integración con APIs externas, despliegue y operación.

## Datos y reportes

pandas, estadística aplicada, Power BI, dashboards de Splunk y Kibana, reportes ejecutivos, calidad de datos, ETL, diseño de esquemas (CIM/ECS).

## Cumplimiento

Auditorías PCI DSS, ISO 27001 y BCRA; gestión de cambios mediante RFC en entornos regulados.
