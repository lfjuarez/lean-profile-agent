# Surface: profile page (/)

Mode: persuade. Audience: SOC leads, CISOs, Splunk partners and recruiters arriving from LinkedIn/Upwork. Job: understand what Lean does, trust it, then download the CV, write, or connect the MCP server.

## Direction contract

THESIS: The profile is a coverage matrix. Every fact is a cell, every question lights the cells that answer it. Refuses the consultant landing (hero, services cards, testimonials) and the dark neon hacker page.

OWN-WORLD: ATT&CK Navigator grammar on a cool white sheet: tactic columns with count headers, square-cornered technique cells with short IDs (LJ-xx), a single green score ramp from white to #0d6b55, amber #e8a317 selection outline, graphite ink. Archivo for all text, JetBrains Mono only for cell IDs and counts.

STORY: The visitor sees a real person (portrait) and a dense map of documented work, asks one question, watches the cited cells light in order, reads a sourced answer, then takes the CV or writes.

FIRST VIEWPORT: Left rail 300px: portrait, name, certifications in order, CV (primary) and email. Right: query bar, answer strip, then the eight-column matrix filling the width.
